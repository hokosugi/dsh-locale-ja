## 手で直す手順

1. `review/<名前空間>.tsv` の `ja` 列を直す（セル内で Enter は押さず、段落は `\n\n` と書く）
2. `npm run review:apply` で辞書へ反映（問題があれば 1 バイトも書かずに中止）
3. `npm run check` でビルド + 監査 + 実物ランタイム検証

`review/*.md` は閲覧専用です。直しても反映されません。
